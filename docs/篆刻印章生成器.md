# 应用商店发布信息 — 篆刻印章生成器

## 简短标题
篆刻印章生成器 — 印章排版设计与导出工具

## 简短描述
本地离线的印章排版设计工具，支持公章、方章与自由排版，实时预览做旧效果，一键导出高清 PNG 与矢量 SVG 文件。

## 完整描述
篆刻印章生成器是一款完全本地运行的印章排版设计辅助工具，帮助用户在电脑端快速生成形制规整、比例协调的印章图案。传统印章设计依赖专业设计软件，排版门槛高、调整耗时；本工具将印章形制、文字环绕、边框与线宽等要素参数化，无需设计基础也能在几分钟内完成一枚布局规范的印章设计稿，适合制作参考、教学演示与设计草模等场景。

在版式能力上，软件提供圆形、椭圆与方形三种外形，覆盖公章、方章与自由排版三种编排模式，并支持朱文（阳文）与白文（阴文）两种印面风格。边框支持单线、双线与无边框样式，线宽与双线间距均可精确到像素调整。公章模式下可编辑上弧文字、下弧文字与中心元素，中心元素支持文字与五角星；方章与自由排版支持多行文本的增删与逐行编辑，满足落款章、名章等多样化需求。

在细节调整上，软件提供像素级微调面板：上弧字号、上弧字距、上弧张角、上弧边距，下弧字号、下弧字距、下弧张角、下弧边距，以及中心字号、中心行距、中心上移与上下留白均可独立调节，使文字沿圆周均匀分布、整体重心平稳。印色支持朱红、红、蓝等常用色并可自定义，字体可选宋体、楷体、黑体等常见字重与加粗组合。

做旧效果是本工具的特色功能：开启后可调节磨损强度、磨损区域大小与位置、边缘羽化等参数，通过噪点纹理模拟真实印章的斑驳质感，预览与导出结果严格一致。软件内置公司公章、合同专用章、财务专用章、个人名章四套预设与一键恢复默认，常用参数一次点击即可到位。

在技术实现上，软件基于 Rust 与现代 Web 技术构建，冷启动迅速、资源占用低，设计过程全程实时预览、所见即所得。导出支持 3 倍高清透明背景 PNG 与可无损缩放的矢量 SVG，放大后依然清晰，便于后续排版与印刷参考。全部渲染均在本地完成，不上传任何设计内容。

无论是为合同附件制作印章样稿、为演示文稿生成示意图案，还是对比不同印色与做旧程度下的视觉效果，篆刻印章生成器都能以参数化、可视化的方式显著提升草图阶段的工作效率，是办公、教学与设计参考场景中轻量可靠的辅助工具。

试用功能限制说明：软件的全部设计功能与实时预览可直接使用；「导出 PNG / 导出 SVG」为完整版功能，需在应用内一次性开通（本机生效），开通后无任何其他功能限制。

## 功能特性
1. 设计圆形与方形印章
2. 切换朱文与白文印面风格
3. 编辑上弧与下弧环绕文字
4. 设置中心文字与五角星元素
5. 调整边框样式与线宽粗细
6. 微调弧形文字字距与张角
7. 自定义印章印色与字体
8. 开启做旧磨损质感效果
9. 调节磨损强度与区域参数
10. 应用四套常用印章预设
11. 实时预览所见即所得
12. 导出高清透明背景 PNG
13. 导出可缩放矢量 SVG
14. 新增与删除多行文本
15. 一键恢复默认设计参数
