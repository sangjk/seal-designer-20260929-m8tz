# 应用商店发布信息 — 印章生成器

## 简短标题
印章生成器 — 印章排版与设计工具

## 简短描述
印章生成器是一款专业的印章排版与设计工具，支持圆形、方形等多种样式，可自由编辑文字、边框、印色与做旧效果，并导出高清图片与矢量文件，满足日常印章设计参考需求。

## 完整描述
印章生成器是一款专注于印章排版与设计的辅助工具，旨在帮助用户在电脑端快速生成各类样式规整、比例协调的印章图案。传统印章设计往往依赖专业设计软件，操作门槛高、排版耗时。本工具将印章的形制、文字环绕、边距与线宽等参数模块化，用户无需掌握复杂设计技能，即可在数分钟内完成一枚符合视觉规范的印章设计稿，适用于制作参考、教学演示与设计草模等场景。

在核心功能方面，软件提供圆形与方形两种基础外形，并支持朱文、白文两种印面风格，覆盖公章、财务章、合同章、法人章、发票章等常见类型。边框支持单线、双线与粗线样式，线宽可自由调整。中心元素可选文字、五角星或二维码图形；上弧与下弧文字均可独立编辑，配合精细调整面板，可对上弧字距、上弧边距、下弧字距与字号进行像素级微调，使文字沿圆周均匀排布。印色支持朱红、红、蓝等常用色，并可开启做旧效果，调节磨损强度与区域大小，模拟真实印章的斑驳质感。

在技术实现上，软件基于 Rust 与 Web 技术构建，启动迅速、运行稳定，在主流 Windows 设备上的资源占用低。设计过程全程实时预览，参数调整即时反映在画布上，所见即所得。导出图片采用高清位图与矢量格式，保证放大后依然清晰，便于后续排版与印刷参考。

在日常工作中，用户可用它快速制作合同附件所需的印章样稿、为演示文稿生成示意性印章、在设计稿中预览不同印色与做旧程度下的视觉效果，或为教学讲解展示印章的结构与排版原理。对于需要对比多种样式、探索不同形制组合的用户而言，本工具亦能显著提升草图阶段的工作效率。

总体而言，印章生成器以轻量、直观、专业的方式，降低了印章图案的设计门槛。它以参数化与可视化的设计思路，让每一枚印章都规整美观、可控可调，是办公、教学与设计参考场景中值得信赖的辅助工具。

## 功能特性
1. 设计圆形与方形印章
2. 切换朱文与白文风格
3. 选择常见印章类型
4. 调整边框线条粗细
5. 编辑中心文字内容
6. 设置弧形排布文字
7. 微调上下弧字距
8. 自定义印章印色
9. 开启印章做旧效果
10. 调节磨损强度大小
11. 实时预览印章效果
12. 导出高清 PNG 图片
13. 导出矢量 SVG 文件
14. 一键重置默认参数
15. 切换多种预设模板
